# Тайна лунного фонаря

Детская детективная браузерная игра с пятью локациями, русской озвучкой и управлением мышью или касанием.

Играть: https://webbrokers.github.io/mavis-moon-lantern/

## Локальный запуск

`python3 -m http.server 18747`

Открыть http://localhost:18747/. Сборка и серверная часть не нужны.

GitHub Pages публикует корень ветки `main`.
